# Calculadora-Tarea1.3
Calculadora en lenguaje C Usando librerias personalizadas

Un programa ejecutable por consola desarrollado en lenguaje C para realizar operaciones matemáticas básicas, usando librerías personalizadas (.h y .c).

## 🚀 Características
Operaciones soportadas: Suma, resta, multiplicación y división.
Validación de datos: Controla errores críticos como la división entre cero.
Librerías personalizadas: Las operaciones están separadas en archivos .h y .c propios.
Interfaz ligera: Funciona completamente desde la terminal o consola de comandos.


## 🛠️ Requisitos Previos
Para compilar y ejecutar este programa necesitas tener instalado un compilador de C:

GCC (GNU Compiler Collection) o Clang.
Nota para Windows: Puedes usar MinGW o compilar desde Code::Blocks.


## ⚙️ Instalación y Compilación
Clona el repositorio:

git clone https://github.com/Misael0435/Calculadora-Tarea1.3.git

cd Calculadora-Tarea1.3

Compila el proyecto:

gcc main.c operaciones.c -o calculadora


## 💻 Cómo Usarlo
En Windows:

calculadora.exe

En Linux / macOS:

## ./calculadora
🖥️ Ejemplo de ejecución en consola:
=== CALCULADORA EN C ===

1. Sumar

2. Restar

3. Multiplicar

4. Dividir

========================

Selecciona una opcion (1-4): 1

Introduce el primer numero: 12

Introduce el segundo numero: 8

Resultado: 20.00

========================
